## 🧾 Descrição Geral

Este aplicativo Android permite inserir o salário atual de um funcionário e selecionar um percentual de aumento (40%, 45% ou 50%) utilizando `RadioButtons`. O novo salário é exibido após o cálculo.

## 🚀 Funcionalidades

- Inserção do salário atual;
- Seleção do percentual de aumento com `RadioButton`;
- Exibição do salário reajustado com o novo valor.

## 💡 Processo de Desenvolvimento

A lógica de aumento foi feita com base na opção escolhida. Esta questão me ajudou a consolidar o uso de `RadioGroup` e a prática de cálculos dinâmicos com entradas do usuário.
